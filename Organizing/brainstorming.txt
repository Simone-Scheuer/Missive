## Project Specs, and how it aligns with Melinas vision:

This application consists of a chat server and multiple chat clients (users):

- Clients can send messages to other clients through the server.
- Clients can receive messages from other clients through the server.
- The server accepts connections from the clients.
- The server delivers real-time messages between clients over the Internet.

- Frontend Functionality
    - Send and receive messages in real-time through a simulated backend.
    - Ensure smooth navigation between different chat rooms and views.
    - Display error messages for authentication or connection issues.
- Ensure seamless integration with the backend for real-time messaging, authentication, and database updates

Backend Focus:

- Server Functionality
    - Handle user authentication (registration, login, logout)
    - Support storing and updating users’ first and last names in the database.
    - Enable the creation and deletion of chat rooms.
    - Maintain a database to store user credentials, messaging history, and a list
    of created chat rooms and their participants.
    - Enable real-time messaging functionality between connected clients.
- Database Management
    - Store and retrieve data efficiently for all features.
    - Handle error cases, such as invalid user actions or database failures.
- Provide robust APIs for frontend communication.
